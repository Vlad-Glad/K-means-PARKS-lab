# PARCS.NET

Базова платформа для розподілених обчислень на C# / .NET 10. Джерело: [parcs8](https://github.com/alexeybogusevich/parcs8).

Модулі реалізують `Parcs.Net.IModule` і виконуються на вузлах PARCS, обмінюючись даними через TCP-канали.

| Компонент | Призначення |
|---|---|
| `Parcs.Host` | Приймання завдань і керування виконанням |
| `Parcs.Daemon` | Виконання модулів на обчислювальних вузлах |
| `Parcs.Portal` | Вебінтерфейс для модулів, завдань і результатів |
| `Parcs.Core`, `Parcs.Data` | Спільні механізми платформи та зберігання даних |

Вихідний код сервісів розташований у `src`, приклади модулів — у `modules`.
